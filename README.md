# chipped-mug

**Understand the change.**

A small skill that explains what a selected code change actually does.

Give it a pull request, branch, commit, or diff. It uses the repository as context and explains the change in plain product and system language.

For people who understand the product, but don't necessarily know the codebase.

## What it does

`chipped-mug` helps explain:

- what changed;
- what happened before;
- what happens now;
- when the difference matters;
- how the change fits into the existing system.

## What it doesn't do

It doesn't review the code, look for bugs, design tests, or judge whether the implementation is good.

It explains the change.

You take it from there.

## Status

Beta.

Currently being tested on real repositories and different kinds of changes.

Feedback is very welcome.
