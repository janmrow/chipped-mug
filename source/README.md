# Warm Print artwork

These are the editable sources for the two published images. Keep the SVGs, `illustration.png`, and `font.ttf` in this directory so their relative references resolve. Install the bundled Libre Baskerville font before editing the SVG text.

| Source | Published export |
| --- | --- |
| `hero.svg` — 1600 × 480 | `../assets/hero.png` — 3200 × 960 |
| `social-card.svg` — 1280 × 640 | `../assets/social-card.png` — 2560 × 1280 |

Export at 2× with the full warm ivory background and sRGB color profile. Keep the social card below 1 MB. Use `assets/social-card.png` in the repository’s Settings → Social preview → Edit → Upload an image. Adding the file to Git does not set the preview.

The illustration was created with imagegen; the typography and layouts were composed separately. Artwork and layouts use the repository’s [MIT license](../LICENSE). The unmodified font retains its [SIL Open Font License 1.1 and copyright notice](OFL.txt).
