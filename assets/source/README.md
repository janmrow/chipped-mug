# Artwork sources

For complete previews, use [hero.png](../hero.png) or [social-card.png](../social-card.png). The SVGs are editable layouts; image previews may omit their linked illustration or font.

To edit, install the bundled Libre Baskerville font (`font.ttf`) and open the SVGs in Inkscape. Keep the SVGs, `illustration.png`, and `font.ttf` together so their relative references resolve.

| Source | Published export |
| --- | --- |
| [hero.svg](hero.svg) — 1600 × 480 | [hero.png](../hero.png) — 3200 × 960 |
| [social-card.svg](social-card.svg) — 1280 × 640 | [social-card.png](../social-card.png) — 2560 × 1280 |

Export at 2× with the full warm ivory background and sRGB color profile. Keep the social card below 1 MB. Upload the exported `assets/social-card.png` through the repository’s Settings → Social preview → Edit → Upload an image. Adding the file to Git does not set the preview.

The illustration was created with imagegen; the typography and layouts were composed separately. Artwork and layouts use the repository’s [MIT license](../../LICENSE). The unmodified font retains its [SIL Open Font License 1.1 and copyright notice](OFL.txt).
